## Важно для следующей сессии

Живой сайт новее, чем код в GitHub (на сайте есть /price, /stati, /elektrik, /raboty, /studio — в ветках их нет).
Исходники лежат на сервере или на компьютере. **Перед правками скачать текущую версию с сервера**,
а не брать файлы из веток GitHub — иначе затрём новые страницы.
После правок положить копию исходников в GitHub, чтобы база была одна.
