# Как подключить бота MAX к автопостингу

**Токен бота — секрет. Не присылать его в чат с Claude и не писать в GitHub.**
Он вводится один раз в файл настроек на сервере (или на компьютере, где работает crosspost.py).

## Быстрый способ (как обычно)

В сессии на компьютере Claude открывает окно браузера/Блокнота с `crosspost.env` — владелец вставляет туда токен, Claude продолжает сам. В облачной сессии так нельзя: она не видит экран компьютера.

## 1. Взять токен

1. https://business.max.ru → ваш бот → «Чат-боты» → «Интеграция» → «Получить токен».
2. Скопировать токен (длинная строка).

## 2. Добавить бота в канал

MAX → канал «Бриллиант Энерджи | Brilliant Energy» → Участники → Администраторы → добавить бота → право «Публиковать сообщения».

## 3. Вписать токен

Файл `crosspost.env` (лежит рядом с `crosspost.py`, сделан в сессии «Анализ бренда» на компьютере). Открыть Блокнотом и вписать:

```
MAX_TOKEN=сюда_токен
```

Остальные строки (ID канала, ВК) не трогать, если не знаете — Claude в сессии на компьютере допишет сам.
Сохранить. Файл никому не пересылать.

## 4. Запуск

В сессии на компьютере сказать Claude: «Токен MAX вписан в crosspost.env. Проверь подключение и поставь crosspost на сервер, запуск каждые 15 минут».
Claude проверит токен запросом к API MAX (не показывая его), найдёт ID канала и сделает тестовый пост.
