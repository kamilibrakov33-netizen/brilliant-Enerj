# СИРИУС — общая база проекта Brilliant Energy

Одно место, где собраны все сессии с Claude, что сделано, где лежит и что осталось.
Каждая новая сессия начинает отсюда, каждая сессия в конце дописывает сюда.

## Файлы

| Файл | Что в нём |
|---|---|
| `СТАТУС.md` | Главное: что работает, что сломано, что ждёт. Читать первым. |
| `ДЕЛА.md` | Список дел: что делает владелец, что делает Claude. |
| `СЕССИИ.md` | Журнал всех сессий: дата, тема, итог, где результат. |
| `ПРОВЕРКА_САЙТА.md` | Последняя проверка живого сайта: что работает, что расходится. |
| `РЕКЛАМА.md` | Готовые рекламные тексты, что можно запускать и что мешает. |
| `КАРТОЧКИ.md` | Тексты для Яндекс Карт и 2ГИС. |
| `MAX_БОТ.md` | Куда вписать токен бота MAX. |
| `ГДЕ_ЧТО_ЛЕЖИТ.md` | Сайт, бот, ветки GitHub, папки на компьютере, сервисы. |

## Правило для каждой сессии Claude

1. В начале: прочитать `sirius/СТАТУС.md` и `sirius/ДЕЛА.md`.
2. В конце: добавить строку в `sirius/СЕССИИ.md`, обновить `СТАТУС.md` и `ДЕЛА.md`, закоммитить и отправить в GitHub.
3. Пароли, ключи, токены, паспортные данные и реквизиты сюда **не писать никогда**. Только «где лежит», не «что внутри».

## Как дать сессии доступ к базе

- Облачная сессия (claude.ai/code) с репозиторием `brilliant-Enerj` видит базу сама.
- Сессия на компьютере: скажите Claude «прочитай базу Сириус» — он откроет её из GitHub
  (`kamilibrakov33-netizen/brilliant-Enerj`, папка `sirius/`) или из локальной копии репозитория.
